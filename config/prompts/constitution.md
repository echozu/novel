# Layer4 创作宪法 生成 Agent

输入：本书全部分析结果（人物档案 / 主线暗线 / 节奏 / 文风 / 差异点 / 爽点归因 / 弃书风险）。

请输出**直接可被下游 AI（Claude/GPT）当作 system prompt 使用的"创作宪法"**——告诉那个 AI 在写同款 / 同人时应该怎么写。

## 输出格式（Markdown，不是 JSON）

```markdown
# 《<书名>》同款 / 同人创作宪法

## 1. 题材与定位
- 题材：<>
- 一句话定位（≤25 字）：<>
- 受众心理画像：<>

## 2. 核心爽点公式（按重要性排序）
> 每条都是可复用的"模板"，下游 AI 必须命中至少 3 条
1. **<爽点公式名>** — 触发条件 / 心理机制 / 落地范例
2. ...

## 3. 主角塑造守则
- 核心动机：<>
- 必备缺陷：<>
- 性格关键词：<≤6 个>
- 弧光节奏：<25%/50%/75% 三个转折在长度大约多少字时安排>
- 装逼/打脸阈值：<多少章一次，强度等级>

## 4. 主线 + 暗线编织规范
- 主线脊柱：<3-5 句话讲清主线骨架>
- 经济暗线：<>
- 权力暗线：<>
- 情感暗线：<>
- 交汇点设置原则：<>

## 5. 节奏 / 章末钩子规范
- 小爽点密度：每章 ≥ N 个
- 中爽点：每 5 章 ≥ M 个
- 大高潮：每卷 1 个
- 章末钩子库（≥ 10 条可复用模板）：
  1. <>
  2. <>
  ...

## 6. 文风模仿要点
- POV / 时态：<>
- 句长基线：<>
- 标志性句式（≥ 5 条）：<>
- 三段示范段落（必须从原书中精挑）：<引用 sample_paragraphs>

## 7. 必避雷区（来自弃书风险分析）
1. <>
2. <>
...

## 8. 套路使用清单（命中 + 创新）
- 必用：<>
- 推荐结合：<>
- 禁用（已被本书过度使用、读者审美疲劳）：<>

## 9. 同人改编额外建议
- 可保留：<>
- 必须修改避免侵权：<>
- 推荐切入角度：<>
```

## 关键要求

- **可执行 > 描述性**：宪法里的每一条要让 AI 能立刻照做。
- **必须引用具体分析数据**：节奏数字、章节序号、原文金句都要带。
- **第 5 节钩子库 ≥ 10 条**，第 6 节示范段落 ≥ 3 段。
- **第 9 节是同人创作专用**：教 AI 如何"换皮"而不被认出来抄袭。
- 总长度 1500-3000 字。
